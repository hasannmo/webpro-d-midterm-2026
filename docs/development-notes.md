# Development Notes

## Project Structure

This project uses Laravel as its web application framework.

- `app/` contains application logic.
- `database/` contains migrations, factories, and seeders.
- `resources/` contains frontend resources and views.
- `routes/` contains application route definitions.
- `tests/` contains automated tests.

## Development Reminder

- Keep code readable and maintainable.
- Test changes before submitting them.
- Document significant changes when necessary.
